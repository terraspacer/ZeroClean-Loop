# V3 interfaces and execution boundaries

`run_study.py` snapshots the v2 runner with a separate study/output root, v3 cohort and schema. `merge_rule_artifacts(table, old, fresh)` forms the stable, origin-namespaced cached-plus-fresh union with exact executable/dependency deduplication. Only criteria/dependencies enter inference. `infer_table(table, source_probabilities, empty_probabilities, source_metadata, seed_repairs, pass2, cts_cells, runtime, log)` accepts that merged pass2 and is the pure orchestration interface used by fictional fixtures. The CLI alone binds real file inputs. `execute_cohort.py` holds one mandatory heavy lock across all-six nine-role schema/static-source preflight, stable snapshot checks, global freeze and serialized inference. Scientific imports follow one-thread and both-limit 12 GiB bounds. Preflight performs no rule evaluation. `freeze_study(root)` validates all six fresh and cached artifacts and hashes all inputs/source without evaluating a rule or constructing inference statistics. `_run_study` is internal; CLI execution encloses it in `heavy_execution`.

`validate_rule_artifact(table, body, packet_sha256=..., response_sha256=...)` validates wrapper identity/schema. `validate_artifact_files(root, dataset)` additionally compares packet/raw-response bytes and exact fresh rules/dependencies canonical JSON equality and nested packet `table.id`/`table.sha256` identity. Artifact checks precede global freeze and each real table load. Sandbox source validation remains mandatory during inference and does not trust wrapper confidence or schema validation as evidence of semantics.

`detection.gate_detection` preserves the old positive gate as `_gate_inherited_detection`, then adds repair-independent negative promotions. It returns policy scores, the strict mask, audit evidence and aggregate/per-column diagnostics. `intrinsic_context` discovers only original-dirty single-column relationships and refuses conflicting modes. All leave-one-out query exclusions are explicit. Fresh LLM dependencies remain dirty-index candidate features and cannot replace the independent intrinsic detection relation thresholds.

`consensus.discover_consensus` is the v2 snapshot. `repair.select_repairs` preserves exact-string proposals and applies the new deterministic catalog gate before candidate ranking. An ineligible higher-ranked candidate cannot hide an eligible lower-ranked candidate. `combined_row_guard` remains a mandatory whole-row check and can roll back all edits on a new rule violation/runtime error, while leaving detection frozen.

Paths/constants: cohort `local-unified-loop-v5-20261030`; schema `unified-loop-v5-freeze-v1`; method map `{"unified_loop_v5":"zeroclean_loop.json"}`; output `results/unified_loop_v5`. Predictions contain exactly `zeroclean_loop.json`, byte-preserved `zeroed.json` and byte-preserved `zeroed_zeroec_reconstruction.json` per table. All nine input roles (including `old_pass2` at `artifacts/llm/{dataset}/pass2.json`) are listed by `input_paths` and included in plan/lock/dataset freezes. Model provenance is copied into diagnostics without alteration.

Runtime defaults and thresholds are included in `configuration_snapshot`. The freeze inventory is exact, including `.py`/`.md` additions/removals and absent initializers. Do not edit source/protocol/test files after creating the real lock. Reports belong in the top-level `reports/` directory and remain outside the frozen method source.
